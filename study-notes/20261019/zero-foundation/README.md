## 编译与恢复

安装TeX Live/XeLaTeX、Noto CJK字体。需要fontspec、amsmath、amssymb、booktabs、array、tabularx、longtable、enumitem、graphicx、xcolor、tikz、fancyhdr、hyperref。

主文件main.tex，运行 `bash build.sh`，输出 build/main.pdf。字体路径默认Linux的 /usr/share/fonts/opentype/noto/；其他系统请改为本机字体位置或字体名称。

源码中的全部示意图均由TikZ生成，无需外部图片文件。无需原始录音、教材全文、模型权重或凭据。PDF附件与源码包分别交付；GitHub仅保存文本源码和校验记录。
