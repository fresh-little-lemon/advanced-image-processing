# 第二阶段：噪声处理与数值尺度诊断

## 实验范围

本阶段在独立工作目录运行，第一阶段快照保持冻结。程序图案包括常量、正弦、棋盘、阶跃、随机纹理；每种图案使用曝光 B={0.7,1,1.3}、六组双源噪声强度和三个固定种子。主网格为 270 条件 × 11 方法，共 2970 行；零方差极限补充为相同 270 条件 × 4 方法，共 1080 行。

全部融合在共同线性 RGB 轨道处理。已知曝光补偿对所有方法一致应用；所有输出针对同一清晰目标评价。灰度噪声方差采用完整协方差传播 `wᵀΣ_RGBw`，独立 RGB 噪声为特例。能量偏置和来源可靠性评价排除半径4的图像边界、饱和像素影响范围；来源准确率额外排除来源分界及清晰/模糊差异不可辨的区域。

噪声均值扣除和方差归一化分别开关。`normalize_variance=False` 使用固定分数尺度 sqrt(1e-8)，与零噪声估计有区别。平坦块候选固定选取平滑导图中梯度最低20%的8×8块，用对角高频残差MAD估计噪声。残差样本的支持在块右侧/下侧扩展1像素；预先腐蚀4像素的有效区保证其支持不含饱和点。覆盖率及所选梯度能量逐条件记录。

## 主要证据

### 噪声不对称时，均值扣除确有作用

非对称噪声条件的平均线性 PSNR：

| 方法 | dB |
|---|---:|
| 单尺度 guided | 31.270 |
| oracle噪声，完整处理 | 34.694 |
| oracle噪声，关闭均值扣除 | 32.206 |
| oracle噪声，关闭方差归一化 | 34.675 |
| 全局噪声估计 | 34.768 |
| 平坦块噪声估计 | 34.537 |

这些条件复用五种基础纹理，属于机制诊断，不应把每行当成独立自然场景。相同噪声水平下的均值扣除在两源差值中会相互抵消，该不变量已由测试核验。

### 干净弱纹理回退有两条不同原因

干净正弦纹理在 σ=0 时，原 energy 结果为49.992 dB，而 guided 为59.182 dB。原固定方差分母 ε=1e-8使零噪声弱能量差仍产生混合权重。把数值极限改为“零方差、非零差值时确定性选择，差值为零时0.5”，恢复至59.639 dB。该修改来自方差趋零的数学极限，未搜索阈值。

清晰随机纹理仍可能使噪声估计产生正值；该机制与数值分母独立。平坦块候选减少了部分纹理污染，但棋盘模式下仍可能高估，且整体噪声条件上没有超过当前全局估计。量化步长回退作为独立工程启发式保留，其阈值是操作尺度，不解释为量化噪声标准差。

### 26组干净验证

验证图像采用 sRGB 解码后的线性工作域，与第一阶段编码域数值分别报告。

| 方法 | 平均线性PSNR / dB |
|---|---:|
| guided | 37.76874 |
| 全局估计，完整处理 | 37.23697 |
| 全局估计，关闭均值扣除 | 37.83371 |
| 全局估计，关闭方差归一化 | 37.24196 |
| 平坦块完整处理 | 37.81229 |
| 平坦块低噪声回退 | 37.77457 |
| 全局估计，零方差极限 | 37.21298 |
| 平坦块估计，零方差极限 | 37.77973 |

完整处理与关闭均值扣除的对比把干净验证上的退化进一步定位到有偏噪声均值校正；关闭方差归一化没有恢复。平坦块候选缓解该现象，平均增益仍较小，尚需独立自然场景检验。零方差修正解决了指定程序反例，并未对所有真实纹理带来统一增益。

## 可靠性与验证状态

提供 raw/smoothed 两套 Brier、ECE、准确率以及有效像素数量。标签来自程序图案中已知清晰来源；常量区没有可辨来源，相关指标留空。guided比较分数为其最终权重，能量方法同时保留平滑前后权重，因此阅读raw对比时需要保留这一处理差异。κ仍固定为4，经验可靠性分数尚未完成独立校准。

21项Python测试通过，覆盖RGB协方差、饱和支持、已知高斯噪声的Monte Carlo能量期望、开关独立性、同噪声扣除抵消、零方差尺度不变性与有限值。测试中的Monte Carlo采用64次随机样本和内区评价。

94组WHU留出、13组外部数据继续封存。实验结果用于确定下一阶段方案。

## 同域完整GFF基线

独立复现的双层GFF `continuous_shared_gray` 在完全相同26组解码线性RGB输入上，平均全图RGB PSNR为38.69456 dB、全图RGB MAE为0.00293465。该PSNR高于当前能量候选；同时guided的MAE为0.00225442，平坦块为0.00248690，均低于GFF的0.00293465，体现不同误差指标间的权衡。下一阶段以完整传统基线作为参照，并共同报告PSNR和MAE。作者操作对齐的编码域配置另行记录，两个域的数值分别比较。方法来源、边界、量化与权重归一化见 `docs/gff_reference_spec.md`；线性域逐图结果见 `results/gff_linear_validation/`。

所有本阶段PSNR均在全图三通道线性RGB计算，MAE也为全图RGB均值。程序图案的boundary_mae在预先固定的中央8列来源分界带上计算。真实WHU没有提供物理焦点边界掩膜，图示采用固定中心裁剪；该裁剪仅供视觉对照，不作为已知物理边界标注。

同一270条件程序网格也运行完整GFF连续线性配置。对称噪声平均PSNR为33.29666 dB，非对称噪声为31.12996 dB；当前全局噪声校正分别为34.905与34.768 dB。在这组已知噪声程序条件上，能量校正也优于完整GFF，而干净WHU仍由GFF取得更高平均PSNR。两类结果共同界定适用条件，后续需要更丰富的独立场景与退化模型。GFF逐条件MAE、固定来源分界带MAE以及PSNR保存在 `results/gff_procedural/`。
