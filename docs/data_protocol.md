# 多聚焦融合数据协议 v1

记录日期：2026-10-17。研究范围为传统多聚焦融合，曝光差与噪声是输入扰动，保持多聚焦重建目标。原图只保留在本地数据目录；项目仓库发布协议、来源和哈希，不发布图像。

## 2. 路径、完整性与许可

数据根目录：环境变量 `MULTIFOCUS_DATA_ROOT` 指定的本地目录。

- `manifest_v1.json`：逐场景、逐文件信息，含绝对路径、角色、SHA-256、字节数、分辨率、Git提交、上游归档成员路径、group_id与split
- `validation_v1.json`、`test_v1.json`、`external_test_v1.json`：算法读取入口
- `metadata/duplicate_audit_v1.json`：与既有pilot的重复筛查记录
- 项目 `data/manifests/`：公开相对路径清单；`scripts/fetch_multifocus_data.py`：固定版本下载及逐文件验证脚本
- `MFI-WHU/MFI-WHU/{source_1,source_2,full_clear}/` 与 `MFFW2/{01..13}/`：未重编码的下载图像

许可必须与下载可达性分开记录。MFI-WHU仓库含MIT许可证，README说明照片来自其他公开数据，逐图商用与再分发权利尚待确认。MFIF镜像未发现许可证，MFFW照片原本来自互联网，逐图授权尚待确认。研究过程保留作者署名与来源，原图、接触表和派生图不上传公共仓库；如需公开示例图或产品使用，先核实相应权利。

## 3. 切分冻结与泄漏审查

v1先按原始图像对的编号建立scene_id，再以重复候选的连通分量建立group_id。同一组所有焦点输入、参考、裁剪、缩放、曝光/噪声/位移变体均继承同一split；切分单位固定为scene/group。

目前使用SHA-256精确匹配，以及64位dHash距离≤8且标准化32×32亮度缩略图MAE≤0.45的保守筛查。新增数据与已使用pilot之间没有触发候选；新增数据内部未触发候选。联系表已检查图像角色与大体内容，但原数据未提供完整相机拍摄会话标识，同场景不同视角、近似裁剪与采集会话的语义审查仍需补充。正式投稿前应完成逐场景人工语义审查和原图来源追踪；发现关联后合并组并重新冻结，旧结果降级为探索结果。

冻结算法：非MFFW组取 `sha256('mff-v1|'+group_id)` 的前8位十六进制转整数，模5等于0进入验证，其余测试；MFFW组全归external_test；与pilot相连则强制归exploration。当前为26/94/13组。切分在任何新数据算法成绩产生之前生成。

算法参数、置信度阈值、预算与停止规则只用既有pilot及26组验证确定。发布配置哈希、代码提交和切分清单哈希之后，才运行94组测试与13组外部测试。看过测试成绩后更改参数必须标记第二轮探索，与首次冻结测试分开记录。微调、失败案例挑选和图例选取均须在报告中说明。

## 4. 可扩大但不混淆的证据范围

本次数据增加了带参考的120组重建样本和13组真实复杂边界样本，用于建立可复现实验；工业采集覆盖另设专项扩展。工业扩展应采集固定照明、可控曝光/ISO、移动台/镜头焦点变化、纹理弱区、反光/半透明材料、细线与文字，按物体和采集会话整组隔离。公开 JointRF 原作者项目 https://github.com/yiqingmy/JointRF 提供未配准显微图像研究线索；本次未下载，不计入实验数。
