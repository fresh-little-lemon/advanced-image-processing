# 多焦点融合项目书审阅说明

审阅对象：《四项图像处理研究项目书(1).md》中“面向曝光差异与噪声的可靠多焦点图像融合”。本说明仅提出修订建议，不改动原稿及其他三项课题。

## 审阅结论

建议定向修订，保留题目、应用背景和“背景与目的—理论与算法—步骤与方法—预期结果”的结构。研究方向仍然成立，但技术路线需要从一般性的“扣噪、可信度与边界融合”收敛到“噪声估计偏差如何改变清晰度比较，以及何时适合施加校正”。计算分配保留为后续验证方向。项目书维持1000—1500字；实验进展、具体跑分、实现状态与演示另列。

## 需要修改的内容

### 研究问题与理论依据

原稿“噪声水平拟由平坦区域或高频子带稳健估计”的表述不足以反映当前问题。现有诊断发现，高频统计会把清晰纹理计入噪声，使两幅图像的方差差估计产生偏移；对局部能量统一扣除这一偏移，可能改变大面积弱纹理区域的来源选择。建议明确研究焦点覆盖率、纹理污染、选块偏差和饱和裁剪对噪声估计的影响，分析估计误差向清晰度判决的传播。

理论部分宜交代曝光映射后的噪声方差传播、平方滤波响应的能量偏置校正，以及两源校正能量差的稳定性。把噪声估计、均值扣除和方差归一化作为可分别检验的环节，避免将最终融合得分的提升直接解释为估噪更准确。交叉采样的具体方案应在核对最新实现与记录后写入；本次原稿审阅尚未将其历史摘要数字当作已核验结果。

### 可靠性与局部精细处理

原稿将“清晰度差及其局部波动”直接用于可信度判断，建议补充支持区域的统计适用性与覆盖情况。现有实验表明，空间覆盖充分仍可能保留纹理污染，覆盖不足也可能包含有用估计，因此不能单凭选块数量或空间分布认定校正可靠。应把失效识别、校正收缩或回退作为待比较策略，并评价误拒绝有用校正的代价。

“将计算集中于模糊边界、弱纹理和来源判断不稳定的位置”应收紧。弱纹理可能缺少可恢复细节，判断不确定并不必然意味着增加计算有收益。建议改为研究不确定性与可恢复细节共同指导的局部精化，在相同实际耗时或处理面积下与随机选区、仅边界选区和全图处理比较。

### 数据组织与实验评价

原稿以Lytro和EDMF为主要实验对象，需更新为目前实际建立的数据路线：MFI-WHU的26个验证场景用于开发，94个保留场景用于冻结后的测试；13组MFFW2作为外部保留集。Lytro和EDMF已有探索使用记录，适合补充真实曝光与局部伪影分析。原场景及其裁剪、噪声种子和曝光变化应保持在同一划分，避免开发反馈进入保留测试。

受控实验除曝光、噪声和错位外，应加入清晰区域占比、噪声方向交换、裁剪和残差筛选条件。评价同时覆盖噪声方差差误差、来源选择风险、全参考重建质量及边界误差。MFI-WHU按参考图像重建误差产生的偏好标签不等同于物理焦点标签；后者应使用保存生成掩膜的受控轨道。全参考指标统一计算域，线性RGB与亮度Y指标分别汇总，配对统计以场景为单位。

保留平均融合、局部硬选择、引导滤波等对照，并增加经数值核验的完整GFF强基线。现有原始输入实验中，修正噪声估计并不代表全面超过GFF，因而预期结果宜强调适用条件、误差机制与质量—成本关系，避免预设普遍优势。

### 实现目标与预期结果

应明确采用传统图像处理方法，使用Python建立可复现实验，以C++实现关键模块和完整处理流程，并在PC及实际目标端侧平台评价数值一致性、延迟和内存。完整流程、模块计时与ARM实测分别验收。尚未验证的完整管线速度、实时性或端侧性能不宜写成已具备能力。

原稿中的图像对输入、可靠性图和融合结果输出可作为预期原型功能保留；当前代码完成程度、测试数量、运行时间与演示图移入独立进展材料。
